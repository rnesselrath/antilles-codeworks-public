Security Statement

App Name: Release Report (Jira Cloud App)

Last Updated: October 2026

Security Summary: Release Report is an Atlassian Forge app. Its backend functions run on Forge, and its user interface runs in the browser within Jira. The app uses Jira and Confluence APIs as the current user. The app manifest does not declare an external backend or external network destinations. For data categories, storage and retention, see the Privacy Policy.

1. Architecture & Access

The app uses Atlassian Forge for backend functions and Atlassian product APIs:

  • Platform: Backend functions run on Atlassian Forge. The user interface runs in the browser as part of Jira.
  • API authorization: Jira and Confluence requests are made as the current user and are subject to that user's Atlassian permissions.
  • External services: The current app manifest does not declare an external backend, external network destinations, or an analytics service. This statement reflects the current implementation and may change in a future version.

2. Security Responsibilities

  • Platform infrastructure: Atlassian operates the Forge platform. Details about Forge security and storage are maintained in Atlassian's Forge documentation.
  • App maintenance: The developer maintains the app source code and dependencies. Security-relevant updates should be reviewed and deployed by the developer.
  • No security guarantee: This statement does not claim that every dependency is continuously audited, or that vulnerabilities cannot occur. It does not describe specific encryption or vulnerability-scanning controls.

3. Reporting a Security Concern
