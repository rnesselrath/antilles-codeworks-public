Privacy Policy for Release Report

Last Updated: October 2026

1. Overview

Release Report ("the App") is an Atlassian Forge application that helps users select Jira project versions, review and format related issues as release notes, and optionally publish those notes to Confluence. This Privacy Policy explains how the App handles data when you use it.

2. Architecture & Data Transfers

The App is built on Atlassian Forge. In the version covered by this policy, the App uses Forge functions and Forge-hosted storage, and its manifest does not declare an external backend or external network destinations.

  • No third-party backend or analytics: The current version does not send App data to an external server or third-party analytics service. This describes the current implementation and may change if the App is updated.
  • Atlassian APIs: The App requests Jira and, when used, Confluence data through Atlassian APIs as the current user. Forge-hosted storage is provided by Atlassian.
  • Browser processing: Jira data and App settings are sent to or handled by the App's user interface in the browser. Therefore, data processing is not limited to Atlassian's server infrastructure. Users may also copy generated release notes or ask the App to publish them to Confluence.

3. Data Processed by the App

To generate and manage release notes, the App may process the following information from Jira:

  • Project and version data: Project names, keys and IDs, and version names, IDs and release status, to let the user choose what to review.
  • Issue data: Issue keys, summaries, issue types, statuses, priorities, components, labels, fix versions and project information. Where available, the App also reads the Jira team field. It also requests Jira field and priority metadata to support issue display and sorting.
  • Summary overrides: Replacement issue summaries entered by a user in the App.

When the user opens the Confluence publishing flow, the App can retrieve Confluence spaces and pages to let the user choose a destination. If the user requests publication or an update, the App sends the release-note content to the selected Confluence page or space.

4. Personal Data (PII)

The App does not request Jira user names, email addresses or IP addresses as issue fields for release-note generation. However, Jira issue summaries, labels, team-field values, or other content supplied to the App may contain personal information. The App may process that information in the browser and, for summary overrides, in Forge-hosted storage. The App does not send it to an external server in the current implementation. Users should avoid including personal information in release notes unless appropriate for their use case.

5. Data Storage & Retention

  • Summary overrides: User-edited summary overrides are stored in Forge-hosted Key-Value Store, associated with the App installation.
  • App preferences: Preferences such as the selected version, sorting options and Confluence destination are stored in the browser's local storage. They are not stored in Forge-hosted storage. Browser data may remain after the App is uninstalled; users can clear it through their browser's site-data settings.
  • Retention after uninstall: Atlassian's Forge storage documentation describes a retention and deletion lifecycle for hosted data after an App is uninstalled. The data may be retained for a limited period before permanent deletion; Atlassian currently documents a 28-day retention period for Forge-hosted storage after uninstall. Reinstalling the App does not automatically restore data from the previous installation.

6. Permissions (OAuth Scopes)

The current App manifest requests the following scopes:

  • read:jira-work: To retrieve Jira project, version and issue data.
  • read:space:confluence and read:page:confluence: To retrieve Confluence spaces and pages for destination selection.
  • write:page:confluence: To create or update a Confluence page when the user requests publication.
  • storage:app: To store and retrieve summary overrides using Forge-hosted storage.

7. GDPR Compliance

The use of Atlassian Forge does not by itself establish compliance with the General Data Protection Regulation (GDPR) or other privacy laws. Whether and how those laws apply depends on the data and the circumstances in which the App is used. Customers are responsible for assessing their legal obligations and for ensuring that any personal information included in Jira content or release notes is handled appropriately.
